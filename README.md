# CritMatch-Software

Research Criteria Matching Software.

## Project location

The application code is in `critmatch_starter/`:

- `critmatch_starter/apps/web` (Next.js frontend)
- `critmatch_starter/apps/api` (FastAPI backend)
- `critmatch_starter/apps/worker` (background worker)

## Deployment

- Netlify config: `netlify.toml` (repo root)
- Render Blueprint config: `render.yaml` (repo root)

See `critmatch_starter/docs/deployment.md` for platform settings and environment variables.
